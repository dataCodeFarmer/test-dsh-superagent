# TeamRelay 文档审阅清单

当前试点仅处理根目录的 `README.md`、`README.<语言>.md` 和 `docs/` 下的 Markdown 文件，不执行源码或 Shell 命令。

维护者启用后台自动准备后，系统收到授权范围内的新需求时会自动准备差异，无需维护者逐项手动启动。维护者按以下清单审阅和发布变更。

- [ ] 核对目标、验收条件和文件范围，确认差异只涉及本次需求指定的文档。
- [ ] 对照仓库现有资料核实事实、路径和示例；无法核实的说明标为待确认。
- [ ] 检查正文和示例，确认不含账号凭据、密码、访问令牌、密钥或私密聊天内容。
- [ ] 审阅完整差异，确认上述检查通过后，再发布草稿 PR。
- [ ] 由维护者审阅草稿 PR，确认反馈已处理、验收条件已满足，再决定是否合并；不自动合并。
